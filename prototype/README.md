# Дизайн сайта Cat First — прототип

Статический прототип в стиле образца Google Stitch («Serene Feline Care», архив
`stitch_cat_first_marketing_website.zip`), исправленный под правила сайта. Тексты и количества — настоящие, из
контента приложения (`assets/content/*_ru.json`).

## Страницы
| Файл | Страница |
|---|---|
| `index.html` | Главная: первый экран, «Почему Cat First», 4 темы, срочные ситуации, «Что нового», оговорка |
| `dom.html` | Раздел «Безопасный дом» (13 тем) |
| `dom-tualet.html` | Статья «Туалет»: содержание, раскрывающиеся разделы, карточки наполнителей, совет |
| `znaniya.html` | Раздел «База знаний» (5 статей) |
| `checklists.html` | Раздел «Чек-листы» (10 списков) и пример чек-листа |
| `srochnye.html` | Раздел «Срочные ситуации» (18) и «Когда к врачу СЕГОДНЯ» |

Снимки: `screens\` — компьютер 1280 px (светлая тема), телефон 390 px, статья в тёмной теме.
Открыть: двойной щелчок по `index.html` (ссылки между страницами работают; политика и поддержка пока `#`). Кнопки магазинов ведут в Google Play и
App Store (https://apps.apple.com/us/app/cat-first/id6811563624).

## Что взято из образца Stitch
Кремовый фон и белые карточки без теней, большие скругления, пастельные плитки с иконками, карточки-строки со
стрелкой, карточка-шапка раздела с картинкой, раскрывающиеся разделы статьи с содержанием сбоку, блоки
«✓ так правильно / ✕ так не надо», зелёный «совет», жёлтая оговорка, тёмно-зелёная полоса «есть в приложении»,
тёмно-зелёный подвал с «Без cookies и сбора данных».

## Что исправлено относительно образца
- **Шрифт.** В образце Plus Jakarta Sans с Google Fonts — в нём нет кириллицы, поэтому русские заголовки в образце
  падали в Times. Здесь системный шрифт, без загрузки с чужих серверов.
- **Иконки.** Material Symbols с Google Fonts заменены встроенными SVG.
- **Tailwind с CDN** заменён своим `style.css`: ни одного запроса к чужим доменам.
- **Убраны кнопка аккаунта** (аккаунтов нет) и **переключатель темы** (тема — по настройке системы, ничего не
  запоминается).
- **Тексты.** Убраны придуманные Stitch обещания («прогресс сохраняется», «персональный календарь прививок и
  напоминания» — это «Мой кот»). Количества разделов и пунктов, описания и оговорка — настоящие.
- **Чек-листы** без отметок, которые запоминаются (это потребовало бы хранить данные в браузере); есть «Распечатать».
- **Меню.** Шапка: «Дом», «Знания», «Чек-листы», «Срочные ситуации», «Поддержка»; на узком экране меню ☰ без JS.
